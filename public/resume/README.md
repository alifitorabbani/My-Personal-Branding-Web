# Resume PDF

Place your CV PDF here as `alifito-rabbani-cahyono.pdf`.

The resume page (`/resume`) links to `/resume/alifito-rabbani-cahyono.pdf`.

Until you add your CV PDF, the download link will return a 404. The resume preview section on the page still displays your professional summary from the local data layer.

Do not commit your actual CV PDF if it contains private contact details (residential address, phone number, etc.) without explicit approval.
