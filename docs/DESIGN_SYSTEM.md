## Typography
| Scale | Font | Use |
|-------|------|-----|
| Display / H1 | Space Grotesk | Hero headings |
| H2–H3 | Space Grotesk | Section headings |
| Body | Manrope | UI and body text |
| Mono | JetBrains Mono | Code, metadata, dates |

## Principles
- Premium, professional, sophisticated, minimal
- No excessive gradients, glassmorphism, rounded cards, or childish colors
- Semantic design tokens (no scattered hex values)
- Consistent spacing system (12-column grid desktop)
- WCAG 2.2 AA contrast
- Respect prefers-reduced-motion
