# Roadmap

## Phase 0/1 — Inspection & Planning ✅
- CV inspection and source-of-truth extraction
- PRD, architecture, design system, content guide docs

## Phase 2 — Foundation ✅
- Next.js 16, TypeScript strict, Tailwind v4
- Fonts (Manrope, Space Grotesk, JetBrains Mono)
- Theme provider (dark/light/system)

## Phase 3 — Design System ✅
- shadcn/ui base components (button, card, input, badge, etc.)
- Layout components (navbar, footer, container)
- Mobile navigation sheet

## Phase 4 — Core Pages ✅
- Home, About, Experience, Projects, Project detail
- Skills, Leadership, Insights, Contact, Resume

## Phase 5 — Animation ✅
- Framer Motion page load reveals, hover states, transitions
- Reduced motion support

## Phase 6 — Integration ✅
- Contact API with Zod validation, rate limiting, Resend
- Sitemap, robots, security headers middleware

## Phase 7 — QA (in progress)
- TypeScript strict, ESLint
- Unit, integration, E2E tests
- Accessibility audit (axe-core)
- Lighthouse performance audit

## Phase 8 — Deployment Prep
- Vercel configuration, environment variables
- GitHub Actions CI/CD
- Deployment documentation
